# JavaScript Mini Projects

A curated collection of JavaScript mini-projects demonstrating core programming concepts, DOM manipulation, asynchronous programming, real-world web applications, games, and continuous learning in JavaScript.

This repository serves as a portfolio of small, focused projects built to practice and solidify fundamental front-end development skills using plain HTML, CSS, and Vanilla JavaScript.

## Projects Included

### 1. Calculator App (`/calculator-app`)
A classic, fully functional calculator built with JavaScript. It handles basic arithmetic operations (addition, subtraction, multiplication, division), decimals, and includes an all-clear (AC) and delete functionality.
- **Concepts covered:** Event listeners, DOM manipulation, string parsing, mathematical operations in JS.

### 2. Random Cat Facts App (`/random-cat-facts-app`)
A fun web application that displays random facts about cats at the click of a button. It fetches data dynamically and updates the user interface.
- **Concepts covered:** Asynchronous JavaScript, Fetch API, DOM updates, error handling.

## Technologies Used

- **HTML5:** For structuring the web pages.
- **CSS3:** For styling, layouts (Flexbox/Grid), and basic animations.
- **Vanilla JavaScript:** For the core logic, interactivity, and API integrations without the use of any external libraries or frameworks.

## Project Structure

Each project is contained within its own dedicated folder and follows a standard structure:

```text
javascript-mini-projects/
├── index.html       # The main HTML document
├── css/             # Folder containing stylesheets
│   └── style.css
├── js/              # Folder containing JavaScript files
│   └── app.js
└── assets/          # (Optional) Folder for images, icons, etc.
```

## How to Run Locally

Since these are pure front-end projects, you do not need any build tools or local servers to run them.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/javascript-mini-projects.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd javascript-mini-projects
   ```
3. **Open any project:**
   Simply navigate into the desired project folder (e.g., `calculator-app`) and open the `index.html` file directly in your web browser.
   Alternatively, if you use VS Code, you can use the **Live Server** extension to serve the files.
